Giriş Yap

Kullanıcı adı veya şifre hatalı.

Şifreniz kodun içinde açık metin olarak durmuyor — yalnızca bir özeti (hash) saklanıyor. Yine de bu koruma sunucu tarafında değil, sayfanın kendi kodunda çalışıyor; küçük bir işletme için günlük kullanımda yeterli bir engel, ama banka düzeyinde bir güvenlik değil. Değiştirme talimatı admin.html dosyasının en üstünde.

GitHub'a Otomatik Yayınla

Doldurup kaydettiğinizde, "Kaydet ve Yayınla" butonu değişikliği doğrudan GitHub reponuza yükler — dosya indirip elle yüklemenize gerek kalmaz. GitHub Pages birkaç saniye içinde siteyi otomatik günceller.

Token oluştururken GitHub'da Settings → Developer settings → Fine-grained tokens üzerinden, yalnızca bu repoyu kapsayan ve yalnızca "Contents: Read and write" izni olan bir token oluşturmanızı öneririz — hesabınızın tamamına erişimi olan bir token değil.

Galeri Görselleri

Yüklenen görsel doğrudan GitHub reponuza gönderilir ve menu-data.json otomatik güncellenir — bunun için yukarıdaki GitHub bilgilerinin dolu olması gerekir.

Ana Sayfa Yerleşimi & Metinleri
